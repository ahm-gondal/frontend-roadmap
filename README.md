## Projects

**DevCard** (`02-html/project-devcard/`) - a profile page and a contact form
built with HTML only, no CSS and no JavaScript. All form validation is done with
native HTML attributes: required, minlength, pattern, type="email", min/max and
autocomplete. Every input has a label, radio groups are wrapped in fieldset and
legend, and there is a skip link for keyboard users.

Open `index.html` in a browser to view it.
