Four layouts, no framework

Flexbox, grid and responsive design. Resize the window and every one of these reflows. Only two of them use a media query at all.

1. Flexbox: a toolbar

One row, one axis. justify-content: space-between pushes the groups apart and gap spaces the buttons, so no margins are needed. flex-wrap lets it stack on a narrow screen.

2. Flexbox: the media object

A fixed-size thing next to text that takes the rest. The avatar is flex: 0 0 auto so it never shrinks, the body is flex: 1 so it absorbs whatever is left.

AD

Why flex-shrink matters

Flex items shrink by default. Without flex-shrink: 0 the avatar squashes into an oval as soon as the text gets long. This is the single most common flexbox bug.

02

align-items controls the cross axis

The default is stretch, which makes every item as tall as the tallest. flex-start keeps them at their natural height, which is what these rows use.

3. Grid: cards that fit themselves

One line does the whole thing: repeat(auto-fit, minmax(15rem, 1fr)). Fit as many columns as can hold 15rem, then share the leftover space equally. Three columns on a laptop, one on a phone, and no media query.

  • auto-fit

    Collapses empty tracks so the cards stretch to fill the row.

  • auto-fill

    Keeps empty tracks, so cards stay their minimum size and leave a gap.

  • minmax()

    Sets a floor and a ceiling for a track. The floor is what triggers the wrap.

  • fr

    A share of the space that is left after gaps and fixed tracks are taken out.

  • gap

    Space between tracks only, never on the outside edges.

4. Grid: a page layout that reflows

Named areas with grid-template-areas. The layout is drawn in the CSS as ASCII art, and the breakpoint just redraws the picture. The HTML order never changes, so the reading order stays correct.
